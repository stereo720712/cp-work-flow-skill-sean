# 主任務描述 HTML 模板

貼入禪道主任務的「任務描述」欄位。

將 `{佔位符}` 替換為實際內容。

---

```html
<p>情境（任務問題描述）：</p>
<p>1. {情境描述第一點}</p>
<p>2. {情境描述第二點（視需要增減）}</p>
<p><br></p>
<p>----------業務梳理目的：開發人員梳理出來的邏輯，自己開發用，也讓其他組員知道能協助發想和測試----------</p>
<p>業務梳理Confluence：</p>
<p>後端業務梳理：</p>
<p><br></p>
<p>前端業務梳理：</p>
<p><br></p>
<p>---------------------------------</p>
<p>影響服務:</p>
<p>---</p>
<p>backend</p>
<p>branch：</p>
<p>服務：{後端服務名稱，例如 otc-order-bll}</p>
<p>---</p>
<p>frontend</p>
<p>branch：</p>
<p>服務：{前端專案名稱，例如 otc365-cashier}</p>
```

---

## 使用說明

- **情境描述**：說明為什麼需要這個任務，問題背景或功能目的
- **業務梳理連結**：開發期間再補充 Confluence 連結，建立時可先留空
- **影響服務**：列出所有會動到的後端服務與前端專案，branch 在開分支後填入
- 若有多個後端服務或前端專案，複製對應的 `---` 區塊並排列
